# Portfolio Blog

Website portfolio/blog ca nhan, dung HTML/CSS/JavaScript thuan va deploy truc tiep len Vercel.

## Chinh sua noi dung

- Doi ten, email va bio trong `index.html`.
- Doi danh sach bai viet trong `src/main.js`.
- Thay anh hero tai `public/portfolio-hero.png`.

## Deploy len Vercel

1. Push project nay len GitHub.
2. Vao https://vercel.com/new va import repository.
3. Framework Preset: `Other`.
4. Build Command: de trong.
5. Output Directory: de trong hoac `.`.
6. Bam Deploy.

Vi day la static site, Vercel khong can cai package hay build step.
